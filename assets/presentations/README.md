# Presentations

Material for slides and the pitch.

| Path | What |
|---|---|
| `logo/` | OpenTwin logo: `opentwin-logo.svg` (wordmark, light grounds), `opentwin-icon.svg` (app icon, light and dark), plus PNG and PDF exports |
| `pitch/` | BaselHack 2026 pitch deck, one file per version (`opentwin-pitch-v01.pptx`), speaker notes inside |
| `ci/` | Corporate identity: `README.md` (voice, colours, type, layout) and `tokens.json` (exact colour, type, spacing and radius values) |

The CI is taken from the OpenTwin design system, which reuses the Sprintbox AI design under a new name. Its logo section describes the Sprintbox marks; for OpenTwin use the files in `logo/`.
