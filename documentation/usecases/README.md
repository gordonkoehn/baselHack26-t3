# Use cases

Everything an agent or teammate needs to know about a demo case lives here, in one folder per case.

**This repo is public.** Only add synthetic or anonymised material, with no customer names, real people, contracts or internal numbers. If in doubt, leave it out and post the question in `#usecases`.

## Adding a case
Copy `_template/` to a new folder with a short name, then fill it in:

| Path | What goes in |
|---|---|
| `brief.md` | Challenge, context, goal, and what the test should find out |
| `sources/` | Stakeholder and expert interviews, notes, exports |
| `personas/` | Persona data, images and voice references |
| `test-object/` | The mockup, as screenshots, PDF or HTML, plus a note on how to open it |
| `links.md` | Miro board and other links that stay outside the repo |

Name files so their order is clear, such as `01-stakeholder-interview.md`. Keep each file under 10 MB.
