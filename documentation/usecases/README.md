# Use cases

One folder per demo case. Start with `brief.md`.

**This repo is public:** anonymised material only.

| Path | What goes in |
|---|---|
| `brief.md` | Challenge, context, goal and links such as Miro |
| `sources/` | Files to drop into OpenTwin: interviews, notes, exports |
| `test-object/` | The mockup the persona sees |
| `interview/` | `guide.md`, plus `real-transcript.md` to check persona quality. Keep the transcript out of `sources/` |
